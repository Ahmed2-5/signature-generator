# ✍️ Signature Generator

A beautiful, browser-based signature generator. Enter your first and last name to instantly preview 8 elegant signature styles — then download as PNG or copy as SVG.

## Features
- 8 unique handwritten font styles
- Live preview on white background
- Download as PNG
- Copy as SVG
- No installation needed — pure HTML/CSS/JS

## How to use
Just open `signature.html` in any browser!
